# Student Spending & Budget Analyzer

## Overview
A Google Colab data analysis notebook created for IEEE LGU Student Branch AI/ML Cohort One (Week 4 Task). This project analyzes fictional student spending across different expense categories and payment methods using Pandas, NumPy, and Matplotlib.

## Google Colab Notebook
[Click Here to Open Google Colab Notebook](https://colab.research.google.com/drive/1hpTuvP78Bx4YnOrmUxLJbodE3axpb7P8?usp=sharing)

## Objectives
- Structure raw categorical data into a Pandas DataFrame.
- Explore dataset metrics, data types, and structural summaries.
- Validate data quality by checking missing values and duplicates.
- Perform statistical calculations using Pandas and NumPy.
- Generate visual bar charts using Matplotlib to interpret spending trends.

## Core Libraries Used
- **Pandas**: DataFrame manipulation, categorical grouping, and filtering.
- **NumPy**: Numerical aggregation and mean calculations.
- **Matplotlib**: Creating graphical data visualizations.
